# The C# University: Master Advanced Programming Paradigms

Welcome to the official GitHub repository for the Udemy course **"The C# University"**. 

This repository contains all the starting templates, step-by-step branch checkpoints, and final completed source code used throughout the course modules.

## 🚀 Course Structure & Branches

To help you follow along easily, this repository is organized by modules. You can switch between branches using the GitHub branch dropdown or via your terminal.

*   `main` — The final completed solution of the entire project application.
*   `module-01-start` / `module-01-final` — Introduction to C# Delegates & Events.
*   `module-02-start` / `module-02-final` — Generics and Memory Management (C# 2.0).
*   `module-03-start` / `module-03-final` — Functional Paradigms, Lambdas, and LINQ (C# 3.0 & 4.0).
*   `module-04-start` / `module-04-final` — Asynchronous Streams and State Machines (C# 5.0 - 8.0).
*   `module-05-start` / `module-05-final` — Clean Architecture & Functional Records (C# 9.0+).

## 🛠️ Getting Started

### Prerequisites
Make sure you have the following installed on your machine before starting the course exercises:
*   [.NET SDK (v8.0 or later)](https://microsoft.com)
*   [Visual Studio 2022](https://microsoft.com) OR [Visual Studio Code](https://visualstudio.com) with the C# Dev Kit extension.

### Setup Instructions
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd YOUR_REPO_NAME
   ```
3. Checkout the specific module branch you are currently studying:
   ```bash
   git checkout module-01-start
   ```
4. Restore dependencies and run the application to verify your setup:
   ```bash
   dotnet restore
   dotnet run
   ```

## 🤝 Questions & Support

If you get stuck on a coding challenge or encounter a compiler error:
1. Double-check your code against the corresponding `-final` branch for that module.
2. Post your detailed question, including screenshots and error logs, in the **Udemy Q&A Dashboard** for this course.
3. Check the [Issues](../../issues) tab in this repository to see if other students found a solution to the same problem.
